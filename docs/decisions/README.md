# Architecture decisions

This directory records decisions that are expensive to reverse or necessary to
understand later code. Decisions are never deleted; changed decisions are
superseded by a new record.

## Lifecycle

```text
Proposed -> Accepted -> Superseded or Deprecated
```

## Index

| ADR | Status | Decision |
| --- | --- | --- |
| [ADR-0001](0001-clean-room-request-path-first.md) | Accepted | Start with a clean-room request path |

## Template

```markdown
# ADR-NNNN: Decision title

## Status

Proposed

## Date

YYYY-MM-DD

## Context

What problem, constraints, and evidence require a decision?

## Decision

What will the project do, and why?

## Alternatives considered

What credible choices were considered, and why were they not selected?

## Consequences

What becomes easier, harder, constrained, or newly required?
```
